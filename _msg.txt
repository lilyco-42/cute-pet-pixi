fix(ci): 修掉首轮 CI 的三处失败 + 校验器抓到的两个真问题

1. android-shell.yml: 弃用 android-actions/setup-android@v3
   它第一步执行 sdkmanager "tools" "platform-tools"，而新版 SDK 已移除 tools 包，
   报 Failed to find package 'tools' 后 exit 1 —— job 在真正编译之前就死了。
   改为直接复用 runner 预装 SDK，只补 platforms;android-36 + build-tools;36.0.0。

2. scripts/verify_packs.sh: 索引 schema 判定兼容 version 字段
   索引用的是 version:1，pack.json 用的是 schema:1，两种都接受。

3. chibi/pack.json 补 behaviors —— 校验器抓出来的真问题
   pack.json 缺 behaviors 时，src/assets/pack.js 的 behaviors: raw.behaviors || null
   会让行为引擎直接不启动：表现是「桌宠站着不动」且不报任何错（静默降级）。
   chibi 只有一段 idle，所以写了自洽的单动画档位（所有 phase 都指向 idle，
   不像 spine-min 那样引用 Relax/Move/Sit —— 那些 clip 不存在，切过去会崩）。

4. verify_packs.sh 加深校验：behaviors 引用的 clip / after / weights 必须真实存在。

5. 合规闸门改用 git ls-files 判定
   本地开发时 assets/packs/ 下躺着大量烘焙好的第三方素材（被 .gitignore 挡着），
   那不是违规；CI 检出的是干净工作树。用 git ls-files 让两种环境语义一致。

6. 新增 webview/android/build.sh（Linux 版构建脚本，CI 用）
   原 build.ps1 只能 Windows 跑，而 CI 是 ubuntu-latest。

7. .gitignore / .gitattributes 修正
   行尾注释是无效语法：git 会把 "# 注释" 当成模式的一部分，规则静默失效。
   /models/ 带了注释就再也没匹配上，导致 45 MB 版权素材差点入库。
   .gitattributes 的行尾注释则会被当成属性名，报 is not a valid attribute name。

本机自检：
  git ls-files -i -c --exclude-standard  输出为空
  assets/packs 下 git 跟踪的 9 个文件全部属于 chibi
